# Phase 2 — Visual Ecosystem Delivery

## Objective

Make the public site visibly communicate the current strategic architecture:

```text
Samuel Paes -> Visao -> Empresas -> Projetos -> Biblioteca
```

The site should read less like a traditional portfolio and more like an authorial creative ecosystem created and directed by Samuel Carrera Paes.

## Scope

- Reframe the homepage as an ecosystem entrance.
- Present Paes Consultoria as the central operating structure.
- Reinforce BANAL as a company for brand, marketing, communication, retail, campaigns, collabs and value perception.
- Reinforce Verde Burgo as a complete events company with buffet, decor, bar, ceremonial, planning, production and execution.
- Keep Provence Raiz as a project inside Verde Burgo, not as the definition of the company.
- Reframe Biblioteca as the intellectual hub that sustains the companies and public authority.
